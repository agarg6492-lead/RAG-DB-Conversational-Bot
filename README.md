PROJECT SUMMARY

Built an end-to-end Retrieval-Augmented Generation (RAG) chatbot capable of answering natural language questions using data stored in Microsoft SQL Server. 
The application combines vector search, semantic embeddings, transformer-based LLMs, and Microsoft Bot Framework integration to provide conversational access to enterprise data.

The bot is accessible through Microsoft Bot Framework Emulator and can be extended to Microsoft Teams, web applications, or enterprise portals.
